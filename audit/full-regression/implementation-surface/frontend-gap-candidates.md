## Critical and High triage

There are no Critical frontend-only candidates. High candidates are:

- `FE-GAP-001` — PermissionGuard and navigation visibility for ordinary query, history, and settings routes must match backend permissions and suppress unauthorized background requests.
- `FE-GAP-002` — Clear or identity-scope all cached user/session/history/admin/schema data on sign-in, sign-out failure, user switch, and role/permission change.
- `FE-GAP-003` — Enforce and communicate the current maximum question length on the primary Workspace prompt, including paste, keyboard and server-configured boundary behavior.
- `FE-GAP-004` — Deleting a session with an in-flight query must cancel work, suppress late UI results, clean locks/state, and keep Undo semantics coherent.
- `FE-GAP-005` — Legacy and current retry/accept actions must retain the submitted connection, dialect, schema and policy while enforcing retry quotas and complete audit state.
- `FE-GAP-006` — Expose a role policy test client/action/result for POST /admin/roles/{id}/test-policy with safe accessible schema/filter allow-or-block feedback.
- `FE-GAP-007` — Role create/edit UI must enumerate and preserve admin.quotas.manage and admin.security.manage alongside the Phase 5 permission set.
- `FE-GAP-008` — Block or safely merge role saves until full role detail/policies hydrate, and prove failed detail fetch cannot erase persisted policies.
- `FE-GAP-009` — Use one current runtime OpenAPI source and regenerate all frontend operations, request/response/download/redirect types and expected error statuses without manual drift.
- `FE-GAP-033` — Prove that credentials, tokens/cookies, complete prompts, raw hostile input and provider/database/error internals never enter browser-observable DOM, accessibility text, console, storage/cache, rendered error text or downloaded files.

Backend dependencies do not authorize backend remediation. In particular, `FE-GAP-005` depends on the Critical `BE-GAP-001`; this frontend audit only records the cross-boundary effect.
