## Rating rules

Exact means the current observable behavior and relevant contract boundary are directly asserted by current tests/evidence. Partial means some behavior is asserted but at least one independent boundary remains unproved or implementation/test drift exists. Missing means no sufficient reachable implementation/evidence exists. Intentional N/A records dead, superseded, or deliberately backend-only surfaces without inventing a new requirement. A mocked browser test remains Partial when the real backend/browser contract is the behavior under review.

## Frontend/backend API correspondence

The generated SDK exposes 35 application endpoint functions. The frontend also implements wrappers and inline operations, yielding the API rows above. The backend runtime inventory reports 60 application operations, while the normalized static OpenAPI has 35; 25 runtime operations are absent from that artifact. The frontend generation script consumes the stale static artifact, so current roles, quotas, detection, audit search/export/retention and schema operations depend on handwritten or inline calls.

The only requirement-backed runtime operation missing a frontend control/client boundary is `POST /admin/roles/{id}/test-policy` (P5-FR-136). OIDC/SAML login and callback routes are intentionally driven by full-page browser or IdP navigation rather than fetch clients; the legacy global schema refresh, single-role quota lookup and framework documentation routes do not create frontend gaps by themselves.

Dead/unreachable production exports are ResponseFeedbackBar/useUpdateFeedback, standalone useSubmitQuestion/useAcceptQuery/useCreateSession, generated getAdminConnection, and standalone group-mapping mutations. ## Test and evidence interpretation

Current-head reports provide valuable real API/browser evidence, including real Gemini and three-source flows. They do not automatically close narrower frontend boundaries. Most Playwright UI flows use page.route mocks; the shared mock user contains stale permission vocabulary; several mocks use superseded response shapes; the i18n error-state helper reloads before scanning the intended error DOM; and provider-switch full-stack coverage remains skipped. Screenshot-writing specs target tracked evidence paths, so they were not executed and are captured as an artifact-isolation gap.

No product code or tests were changed, and no Vitest, Playwright, build, browser, or live-service command was run for this inventory.
